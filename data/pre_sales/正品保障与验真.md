# 正品保障与验真

## 正品承诺

### 平台承诺
本平台自营商品及品牌旗舰店商品均为**品牌方授权正品**，支持专柜验货、官方售后。

平台对以下情形承担**先行赔付**责任：
- 经品牌方或授权维修点鉴定为非正品
- 商品序列号在国家监管平台查无记录
- 商品包装、配件、标识与官方不符

### 授权链路
平台所有商品均可追溯至品牌方授权的经销商或代理商，中间环节不超过两级。

用户可在商品详情页查看：
- 供应商类型（品牌直营 / 授权经销商 / 授权代理商）
- 授权书编号
- 授权有效期

## 假一赔十规则

### 适用条件
同时满足以下三条，可申请假一赔十：
1. 商品为平台自营或品牌旗舰店销售
2. 持有品牌方、授权维修点或第三方权威检测机构出具的**非正品鉴定报告**
3. 鉴定在签收后 **90 天内** 完成

### 赔付标准
| 情形 | 赔付 |
|------|------|
| 鉴定为非正品 | 退还商品全款 + 按实付金额 10 倍赔付 |
| 鉴定为正品但描述与实际不符 | 按描述不符处理，退一赔三 |
| 无法鉴定 | 平台协助送检，鉴定费用由责任方承担 |

### 申请材料
1. 订单号与商品照片（含序列号清晰可辨）
2. 鉴定报告原件或电子版（需含鉴定机构公章）
3. 鉴定机构资质说明
4. 用户身份证正反面（用于赔付打款实名核验）

### 处理时效
- 材料齐全后 **3 个工作日内** 完成初审
- 初审通过后 **5 个工作日内** 完成赔付
- 争议案件进入平台仲裁，**5-10 个工作日** 出具结论

## 防伪验真渠道

### 官方验真方式

| 品类 | 验真方式 |
|------|---------|
| 手机数码 | 品牌官网「序列号查询」或「保修状态查询」 |
| 电脑办公 | 品牌官网服务页输入 SN 码 |
| 耳机音频 | 品牌官方 App 扫描包装防伪码 |
| 智能家居 | 品牌 App 绑定设备后查看认证状态 |
| 美妆个护 | 品牌官方小程序扫码或客服热线 |
| 母婴食品 | 国家市场监管总局「特殊食品信息查询平台」 |

### 序列号位置
- **手机**：设置 → 通用 → 关于本机；或包装盒背面 IMEI 贴纸；或机身 SIM 卡托
- **笔记本**：机身底部标签；或 BIOS 系统信息
- **耳机**：充电盒内侧或包装盒防伪标
- **手表**：表背刻字；或配对后 App 内查看

## 激活与保修状态查询

### 为什么要查激活状态
已激活的数码产品**不支持七日无理由退货**（见退换货政策）。同时激活日期决定保修起算时间。

### 查询方式
1. 品牌官网「保修与支持」页面输入序列号
2. 显示「激活日期」「保修到期日」「是否在保」
3. 若显示「未激活」或查无记录，需警惕（可能是非正规渠道商品）

### 平台侧说明
平台会在发货前记录商品序列号。若用户查询到的激活日期早于签收日期超过 3 天，可联系客服核查，属于「二次销售」的按新品欺诈处理。

## 品牌授权与渠道说明

### 渠道类型标识
| 标识 | 含义 | 售后责任方 |
|------|------|-----------|
| 自营 | 平台采购并销售 | 平台 |
| 品牌旗舰店 | 品牌方或其全资电商公司运营 | 品牌方 + 平台兜底 |
| 授权专卖店 | 持品牌授权书的第三方商家 | 商家 + 平台兜底 |
| 普通第三方 | 无品牌授权 | 商家 |

> 普通第三方商品不承诺正品，也不适用假一赔十。购买页会明确标注。

### 如何辨别
- 商品详情页顶部标识
- 店铺名称后缀（旗舰店 / 专卖店 / 专营店）
- 客服咨询时可直接询问「是否有品牌授权书」

## 举报与处理

### 举报入口
商品详情页 → 右上角「举报」 → 选择「疑似假冒品牌」

### 处理流程
1. 平台风控在 **24 小时内** 响应
2. 对被举报商品进行抽样送检或要求商家提供授权文件
3. 商家需在 **48 小时内** 提供有效授权证明，逾期商品下架
4. 确认为假冒的，商品永久下架、店铺清退、已购用户全额退款并赔付

### 举报奖励
举报经查证属实的，给予举报人 **¥200 无门槛券** 奖励。同一商品多人举报的，奖励首位有效举报人。

## 常见问题

### 专柜验货被拒怎么办
部分品牌专柜不提供对外验货服务，属正常。可改用：
1. 品牌官方售后网点（免费鉴定）
2. 品牌官方客服电话（提供序列号查询）
3. 第三方权威检测机构（如中检集团）

专柜拒绝验货**不作为**商品非正品的证据。

### 商品没有防伪码是假货吗
不一定。部分品牌（尤其海外版、简装版）本身不设防伪码。判断依据应以**序列号能否在官方系统查询到**为准。

### 海外版和国行版有什么区别
| 项目 | 国行版 | 海外版 |
|------|--------|--------|
| 保修 | 全国联保 | 通常仅店铺保修 |
| 系统 | 中文完整版 | 可能缺少部分本地服务 |
| 发票 | 可开增值税发票 | 一般只能开普票 |
| 价格 | 含税 | 可能更低 |

购买页会明确标注版本，未标注的默认为国行版。

### 拆封后还能验真吗
可以。拆封不影响序列号查询和官方鉴定。但拆封会影响七日无理由退货资格（数码产品激活后不支持）。
