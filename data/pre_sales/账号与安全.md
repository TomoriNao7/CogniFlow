# 账号与安全

## 注册与登录

### 注册方式
| 方式 | 说明 | 是否需实名 |
|------|------|-----------|
| 手机号注册 | 输入手机号 + 短信验证码，设置登录密码 | 否（下单时需实名） |
| 第三方授权登录 | 微信 / 支付宝授权，自动绑定手机号 | 否 |
| 企业账号注册 | 需上传营业执照，人工审核 1-2 个工作日 | 是 |

### 登录方式
- 手机号 + 密码
- 手机号 + 短信验证码
- 第三方账号一键登录
- 已开启的设备可指纹/面容快捷登录

### 登录异常
连续输错密码 **5 次**，账号锁定 **30 分钟**；连续输错 **10 次**，账号锁定 **24 小时** 并需通过短信验证解锁。

## 实名认证

### 什么情况下需要实名
1. 首次下单购买实物商品
2. 购买跨境商品（需提供身份证用于清关）
3. 申请退款、价保、赔付
4. 开通 PLUS 会员付费服务
5. 开通先用后付/分期服务

### 认证方式
- **身份证认证**：填写姓名 + 身份证号，系统对接公安部核验
- **人脸识别**：App 内活体检测，用于高价值商品或异常交易
- **企业认证**：营业执照 + 法人身份证 + 对公账户

### 认证信息能改吗
姓名和身份证号一经认证**不可修改**。如因录入错误需更正，须联系客服提交户籍证明或公安机关出具的证明材料，审核周期 **5-7 个工作日**。

## 密码与找回

### 密码规则
- 长度 8-20 位
- 必须包含字母和数字
- 不能与手机号、身份证号、生日相同
- 不能是连续或重复字符（如 12345678、aaaaaaaa）

### 找回密码
1. 登录页 → 忘记密码
2. 输入注册手机号 → 获取短信验证码
3. 验证通过后设置新密码
4. 若手机号已停用，需走**人工申诉**：提交身份证照片 + 近期订单号 + 手持身份证照片，审核 **3-5 个工作日**

### 密码安全建议
- 不要与其他网站使用相同密码
- 建议每 6 个月更换一次
- 平台不会以任何形式索要密码，包括客服

## 绑定手机与邮箱

### 更换绑定手机
1. 我的 → 账户设置 → 安全中心 → 更换手机号
2. 原手机号验证 + 新手机号验证
3. 若原手机号不可用，走人工申诉流程

### 绑定邮箱
邮箱用于接收电子发票、订单通知、密码找回备用渠道。一个邮箱最多绑定 **3 个** 平台账号。

## 异地登录与设备管理

### 登录保护
- 新设备首次登录需短信验证
- 异地登录（跨越 500 公里以上）会触发二次验证
- 登录成功后向绑定手机发送提醒

### 设备管理
我的 → 安全中心 → 登录设备管理，可查看最近 **90 天** 的登录设备，支持远程下线。

### 发现异常登录怎么办
1. 立即修改密码
2. 在设备管理中下线所有设备
3. 检查订单和收货地址是否被篡改
4. 联系客服冻结账号（客服热线 400-XXX-XXXX，7×24 小时）

## 账号注销

### 注销条件
1. 无进行中的订单（含未收货、售后中）
2. 无未结清的退款、赔付
3. 账户余额、礼品卡余额已用完或已提现
4. 无未完成的纠纷或投诉
5. 无未到期的付费会员服务（或主动放弃剩余权益）

### 注销流程
1. 我的 → 账户设置 → 注销账号
2. 系统校验注销条件
3. 短信验证 + 人脸识别
4. 提交后进入 **15 天冷静期**，期间登录即撤销注销
5. 冷静期满后正式注销，数据按隐私政策处理

### 注销后能恢复吗
不能。注销后账号、订单记录、积分、优惠券、会员权益**永久清除且不可恢复**。如需再次使用需重新注册，历史数据不迁移。

### 注销后发票怎么办
已开具的电子发票在注销前请自行下载保存。注销后无法再通过平台获取，但发票本身的法律效力不受影响。

## 防诈骗提示

### 常见诈骗手法
| 手法 | 特征 | 应对 |
|------|------|------|
| 假客服退款 | 电话称「商品质量问题要给你退款」，索要银行卡号或验证码 | 挂断，通过 App 内客服核实 |
| 刷单返利 | 称「帮忙刷单可返佣金」 | 一律为诈骗，平台从不组织刷单 |
| 冒充公检法 | 称「你的账户涉嫌洗钱」 | 挂断并拨打 110 |
| 中奖信息 | 短信称「恭喜中奖，点击链接领取」 | 不点链接，平台中奖仅在 App 内通知 |
| 代付骗局 | 「朋友」让你帮忙代付订单 | 电话核实本人 |
| 假物流理赔 | 称「快递丢失可三倍赔付」，要求下载屏幕共享软件 | 挂断，理赔只在 App 内操作 |

### 平台绝不会做的事
1. 不会索要登录密码、支付密码、短信验证码
2. 不会要求用户下载「屏幕共享」「远程协助」类软件
3. 不会要求转账到「安全账户」
4. 不会通过私人微信、QQ 联系用户办理退款
5. 不会以「订单异常需取消」为由要求提供银行卡信息

### 被骗后怎么办
1. 立即挂失银行卡、修改支付密码
2. 保留通话记录、聊天记录、转账凭证
3. 拨打 110 报案，同时联系平台客服协助提供订单信息
4. 平台会在收到警方协查函后配合调查

## 常见问题

### 一个手机号能注册几个账号
1 个。同一手机号、同一身份证最多绑定 1 个平台账号。

### 账号被冻结了怎么办
冻结通常因异常交易、投诉纠纷或风控触发。联系客服提供身份证明解冻，审核 **1-3 个工作日**。涉及欺诈的账号不予解冻。

### 能把账号借给别人用吗
不能。账号仅限本人使用，出借导致的损失由账号所有者承担。平台发现账号共用（多地同时登录、收货地址频繁异常变更）有权限制部分功能。

### 收货地址能填别人吗
可以。但退款、赔付会原路退回原支付账户，不会退给收货人。代买场景建议由实际付款人操作。
