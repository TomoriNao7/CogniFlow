# 订单与限购规则

## 下单流程

### 标准流程
1. **选商品**：加入购物车或直接购买
2. **填地址**：选择收货地址，支持自动识别粘贴的地址文本
3. **选配送**：标准配送 / 加急配送 / 门店自提
4. **选优惠**：系统自动匹配最优券组合，也可手动选择
5. **确认订单**：核对商品、数量、金额、发票信息
6. **支付**：选择支付方式完成付款
7. **生成订单**：支付成功后订单进入「待发货」

### 下单限制
- 单个订单最多 **50 个商品行**
- 单个订单金额上限 **¥200,000**（超出请拆分下单）
- 单个订单最多使用 **1 张平台券 + 1 张店铺券 + 1 张品类券**
- 不支持跨境商品与国内商品混合下单

## 限购规则

### 限购类型
| 类型 | 说明 | 常见商品 |
|------|------|---------|
| 单品限购 | 同一 SKU 每人限购 N 件 | 新品手机、限量款 |
| 活动限购 | 活动期间累计限购 N 件 | 秒杀、抢购 |
| 品类限购 | 同一品类限购 N 件 | 茅台等紧俏品 |
| 账号限购 | 同一实名信息下所有账号合并计算 | 全部限购商品 |

### 限购计算口径
- 按**实名身份**计算，不按账号。同一身份证下多个账号合并计数。
- 按**收货手机号**辅助校验。同一手机号下的订单合并计数。
- 下单未支付的订单**占用限购名额**，超时取消后释放。
- 已取消、已退货的订单**不返还限购名额**（防刷单）。

### 超出限购的处理
系统在下单时会提示「超出限购数量」，无法提交订单。已支付但被风控判定为超限的订单，平台有权取消并全额退款。

### 防黄牛措施
1. 同一设备短时间内大量下单触发风控
2. 同一收货地址关联过多账号触发人工审核
3. 疑似黄牛的订单可被取消，账号限制购买紧俏商品
4. 对恶意刷单、虚假交易的账号，平台保留追责权利

## 预售与定金

### 预售流程
1. **付定金**：活动期间支付定金，锁定商品与价格
2. **付尾款**：尾款期内支付剩余金额（通常为活动当天）
3. **发货**：尾款支付后按约定时间发货

### 定金规则
| 情形 | 定金处理 |
|------|---------|
| 按时支付尾款 | 定金抵扣货款 |
| 未按时支付尾款 | 定金**不退**（定金罚则） |
| 商家未按约定发货 | 定金**双倍返还** |
| 商品质量问题退货 | 定金随货款一并退还 |

### 定金膨胀
部分活动定金可膨胀，例如「付 ¥100 定金抵 ¥300」。膨胀部分仅在按时支付尾款时生效，未付尾款则只退不退定金（按定金罚则）。

### 尾款期限
尾款支付窗口通常为 **24-72 小时**，具体以活动页面为准。逾期未付视为放弃，订单自动关闭。

## 订单取消与超时

### 用户主动取消
| 订单状态 | 能否取消 | 说明 |
|---------|---------|------|
| 待付款 | 可随时取消 | 无损失 |
| 待发货 | 可取消 | 全额退款，1 小时内到账 |
| 已发货 | 不可直接取消 | 需拒收或走退货流程 |
| 已签收 | 不可取消 | 走退货流程 |

### 系统自动取消
- 下单后 **30 分钟** 未支付，订单自动取消
- 库存紧张商品（标注「抢购」）保留 **15 分钟**
- 预售商品尾款逾期，订单自动关闭

### 取消后退款时效
- 未支付订单取消：无扣款，无退款
- 已支付未发货取消：即时退款，1 小时内到账
- 使用优惠券的订单取消：券在有效期内退回券包

## 凑单与拆单

### 凑单
为满足满减或券门槛而加购其他商品。凑单商品同样适用七日无理由退货，但需注意：
- 凑单后整单退货会导致满减失效，退款金额按比例重算
- 部分退货导致订单金额低于门槛时，平台会扣回相应优惠

### 拆单
平台可能因以下原因自动拆单：
1. 商品来自不同仓库
2. 含预售与现货混合
3. 含大件商品需单独配送
4. 跨境与非跨境商品混合

拆单后每单独立计算运费与优惠，**可能影响免运费门槛**。拆单会在订单页明确提示。

### 合并支付
多个待付款订单可合并支付，但优惠分别计算，不跨单叠加。

## 库存与到货通知

### 库存显示
- **有货**：可正常下单
- **仅剩 N 件**：库存紧张提示
- **无货**：可设置到货提醒
- **预售**：显示预计发货时间

### 到货通知
无货商品可点击「到货提醒」，到货后通过 App 推送和短信通知。通知不锁定库存，先到先得。

### 库存锁定
加入购物车**不锁定库存**，仅提交订单后锁定 30 分钟。大促期间可能出现「下单时提示库存不足」，属正常竞争结果。

## 常见问题

### 订单提交后能改商品吗
不能。待发货订单只能取消后重新下单。已发货订单需走退货流程。

### 同一个商品买多了能退部分吗
可以。按件退货，退款金额按该件商品实付金额计算（含分摊的优惠）。

### 为什么我的订单被自动取消了
常见原因：超时未支付、风控判定异常、商品售罄、限购超限。订单页会显示具体原因，如有疑问联系客服。

### 限购名额什么时候释放
未支付订单超时取消后立即释放。已支付订单不释放，即使后续退货也不返还。

### 预售商品能和其他商品一起下单吗
不能。预售商品需单独下单，避免尾款与现货订单混淆。
