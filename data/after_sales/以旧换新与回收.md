# 以旧换新与回收服务

## 服务概述

平台提供旧机回收与以旧换新服务，用户可将旧设备折价抵扣新机货款，或直接回收到账户余额。

支持品类：手机、平板、笔记本、智能手表、耳机、相机、游戏机。

## 以旧换新流程

### 三步流程
1. **估价**：在回收页选择品牌型号、成色、配置，系统给出预估价
2. **下单新机**：选择「以旧换新」，旧机抵扣金额直接减免新机货款
3. **寄出旧机**：新机签收后 **7 天内** 寄出旧机，检测通过后完成交易

### 抵扣方式
| 方式 | 说明 | 到账 |
|------|------|------|
| 直接抵扣新机货款 | 下单时即减免 | 即时 |
| 回收至账户余额 | 不买新机，只回收 | 检测通过后 1-3 个工作日 |
| 回收至银行卡 | 需实名认证 | 检测通过后 3-7 个工作日 |

### 以旧换新的额外补贴
部分活动期间，以旧换新可享额外补贴：
- 品牌专项补贴：¥100-500（按品牌活动）
- 平台补贴：¥50-200（按活动）
- 补贴在旧机检测通过后发放

## 估价规则

### 影响估价的因素
| 因素 | 影响程度 | 说明 |
|------|---------|------|
| 型号与配置 | 高 | 容量、版本（国行/海外）差异大 |
| 屏幕状态 | 高 | 有无划痕、碎裂、亮点 |
| 机身成色 | 中 | 边框磕碰、后盖磨损 |
| 电池健康 | 中 | 低于 80% 扣减明显 |
| 功能完好 | 高 | 摄像头、扬声器、指纹/面容 |
| 维修史 | 中 | 非官方维修扣减较多 |
| 配件齐全 | 低 | 原装充电器、包装盒 |

### 成色分级

| 等级 | 定义 | 折价系数（相对全新） |
|------|------|---------------------|
| 准新 | 无明显使用痕迹，配件齐全 | 70%-85% |
| 良好 | 轻微使用痕迹，功能完好 | 55%-70% |
| 一般 | 明显磨损，功能正常 | 35%-55% |
| 较差 | 有磕碰或屏幕划痕，功能正常 | 20%-35% |
| 故障 | 有功能故障 | 5%-20% |

### 预估价与最终价
- 预估价基于用户自述，**不是最终成交价**
- 最终价以检测结果为准
- 若检测结果与用户自述差异较大，最终价可能低于预估价
- 差异超过 **30%** 时，用户可选择**退回旧机**（运费由平台承担）

## 检测与验收

### 检测项目
1. 外观检查（屏幕、边框、后盖）
2. 功能检测（开机、触控、摄像头、扬声器、麦克风、按键、接口）
3. 电池健康度
4. 拆修痕迹检测（防拆标、螺丝痕迹）
5. 序列号核验（是否为报失机、盗抢机）
6. 网络锁/账号锁检查

### 检测时效
- 旧机签收后 **48 小时内** 完成检测
- 检测结果通过 App 推送通知
- 用户有 **48 小时** 确认期，逾期视为同意

### 检测不通过的情形
| 情形 | 处理 |
|------|------|
| 与描述严重不符 | 重新报价，用户可接受或退回 |
| 报失机/盗抢机 | 拒绝回收，旧机退回，运费用户承担 |
| 有账号锁未解除 | 通知用户解锁，7 天内未解锁则退回 |
| 非本人所有 | 拒绝回收 |

## 数据安全

### 寄出前必做
1. **退出所有账号**（iCloud、华为账号、小米账号、Google 账号等）
2. **关闭查找我的设备**（否则无法激活，会被退回）
3. **恢复出厂设置**
4. **取出 SIM 卡和存储卡**

### 平台的数据清除承诺
- 检测环节不读取用户个人数据
- 完成回收后，设备进入数据擦除流程（多次覆写）
- 无法开机的设备做物理销毁处理
- 提供数据清除证明（可申请）

### 数据未清除的后果
若用户未退出账号导致设备被锁，平台无法处理，旧机退回且运费由用户承担。

## 不予回收的情形

1. 报失、被盗、走私设备
2. 有未解除的账号锁/网络锁
3. 非本人所有的设备
4. 企业资产未提供处置授权
5. 存在严重安全隐患（电池鼓包、漏液）
6. 改装机、拼装机、山寨机

## 旧机退回

### 什么情况会退回
- 检测价与预估价差异超 30%，用户拒绝
- 检测不通过（账号锁、报失机等）
- 用户主动取消回收

### 退回运费
| 情形 | 运费承担方 |
|------|-----------|
| 差异超 30% 用户拒绝 | 平台 |
| 账号锁未解除 | 用户 |
| 报失机/盗抢机 | 用户 |
| 用户主动取消（已寄出） | 用户 |

### 退回时效
检测完成后 **3 个工作日内** 寄回，物流时效同标准配送。

## 环保与合规

### 合规依据
回收业务遵循《废弃电器电子产品回收处理管理条例》，合作回收商需持有废弃电器电子产品处理资格证书。

### 环保处理
- 可再利用设备：翻新后进入二手市场（明确标注为二手）
- 不可再利用设备：拆解，贵金属提炼，有害物质无害化处理
- 电池单独处理，不填埋

### 回收凭证
完成回收后可申请《回收证明》，用于企业资产核销或个人留档。

## 常见问题

### 预估价和最终价差很多正常吗
正常。预估价基于自述，最终价基于检测。屏幕划痕、电池健康、拆修史是最常见的扣减项。差异超 30% 可选择退回。

### 旧机还没寄出，能取消吗
可以。新机签收后 7 天内未寄出，回收单自动取消，抵扣金额会从新机订单中扣回（需补足货款）。若已超期，需联系客服处理。

### 以旧换新能和优惠券叠加吗
可以。旧机抵扣视为一种支付方式，不影响优惠券使用。但旧机抵扣金额不参与满减计算。

### 旧机抵扣后新机退货，旧机怎么办
新机退货时，旧机抵扣金额原路退回。若旧机已寄出并完成回收，则旧机不返还，只退抵扣金额。

### 坏了开不了机的还能回收吗
可以，按「故障机」估价，通常为原价的 5%-20%。但电池鼓包、漏液的设备不予回收（安全隐患）。

### 回收的钱要交税吗
个人自用物品回收不属于经营所得，无需缴税。企业资产处置需按财务规定处理。
