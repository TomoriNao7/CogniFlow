# 投诉与纠纷处理

## 纠纷处理总则

平台纠纷处理遵循「**先协商、后介入、再仲裁**」三级机制。用户与商家之间的售后争议，按以下顺序处理：

1. **协商阶段**：用户与商家直接沟通（0-48 小时）
2. **平台介入**：协商不成，申请平台客服介入（24 小时内响应）
3. **平台仲裁**：客服调解不成，进入仲裁流程（3-5 个工作日）

## 什么时候可以申请平台介入

### 触发条件
满足以下任一情形即可申请：
1. 商家拒绝合理售后申请
2. 商家 **48 小时** 内未响应售后请求
3. 商家同意的方案未在承诺时间内执行
4. 商家要求用户承担不合理的费用
5. 商家存在虚假宣传、货不对板
6. 商家拒绝提供发票

### 申请入口
订单详情 → 售后详情 → 申请平台介入

### 申请时限
- 售后申请被拒后 **72 小时内** 可申请介入
- 超过 72 小时需联系人工客服

## 举证责任

### 一般原则
**谁主张、谁举证**。但以下情形由商家举证：

| 情形 | 举证方 | 说明 |
|------|--------|------|
| 商品质量问题 | 商家 | 商家需证明非质量问题 |
| 发货时商品完好 | 商家 | 需提供出库质检记录 |
| 已按约定发货 | 商家 | 需提供运单与揽收记录 |
| 商品与描述不符 | 用户 | 需提供对比截图 |
| 未收到货 | 用户 | 需提供未签收证明 |
| 人为损坏 | 商家 | 需提供检测报告 |

### 有效凭证类型

**用户侧：**
- 商品问题照片（整体 + 特写，需能看清问题部位）
- 开箱视频（连续录制、不可剪辑、需含快递面单）
- 与商家的聊天记录截图（需含时间）
- 物流面单照片
- 第三方检测报告

**商家侧：**
- 出库质检照片/视频
- 快递揽收记录
- 品牌售后检测报告
- 发货重量记录

### 证据无效的情形
1. 照片模糊无法辨认问题
2. 视频经过剪辑或拼接
3. 截图无时间戳
4. 商品已使用痕迹明显但主张「全新未拆」
5. 超出举证期限提交

## 平台仲裁规则

### 仲裁流程
1. 客服介入后 **24 小时内** 联系双方了解情况
2. 双方在 **48 小时内** 提交证据
3. 客服根据证据出具初步意见
4. 任一方不认可，进入仲裁组复核
5. 仲裁组在 **3-5 个工作日** 内出具结论

### 仲裁结论类型
| 结论 | 处理方式 |
|------|---------|
| 支持用户 | 商家承担退款/换货/维修责任 |
| 支持商家 | 售后申请关闭，用户可再次申请 |
| 部分支持 | 按责任比例分摊费用 |
| 无法判定 | 平台先行赔付（限额内），再向商家追偿 |

### 先行赔付
以下情形平台可先行赔付：
- 商家失联或店铺关闭
- 商家保证金不足
- 争议金额 ≤ ¥5,000 且证据充分

先行赔付后，平台向商家追偿，不影响用户权益。

## 赔付标准

### 服务类赔付
| 问题 | 赔付标准 |
|------|---------|
| 延迟发货（超承诺时效） | 订单金额 5%，最低 ¥5，最高 ¥500 |
| 虚假发货（上传假运单） | 订单金额 30%，最低 ¥5，最高 ¥500 |
| 缺货未告知 | 订单金额 10%，最低 ¥5 |
| 物流超时（超承诺时效） | ¥10/天，上限 ¥100 |
| 商品破损（配送原因） | 全额退款或换新 + 运费补偿 |
| 商品丢失（配送原因） | 全额退款或补发 |

### 商品类赔付
| 问题 | 赔付标准 |
|------|---------|
| 假货 | 退一赔十（详见正品保障） |
| 描述不符 | 退一赔三 |
| 质量问题（三包内） | 退货/换货/维修 + 运费补偿 |
| 发错货 | 换正确商品 + 运费补偿 + ¥20 补偿券 |
| 漏发 | 补发 + 运费补偿 |

### 赔付上限
单笔订单赔付总额不超过订单实付金额的 **10 倍**（假货情形按假一赔十单独计算）。

## 恶意行为的处理

### 用户侧恶意行为
| 行为 | 处理 |
|------|------|
| 恶意退货（调包、穿后退） | 拒绝售后，账号限制 |
| 虚假举证 | 关闭售后，情节严重冻结账号 |
| 恶意投诉敲诈 | 移交法务，保留追诉权 |
| 职业打假（超出合理维权） | 按正常流程处理，不额外赔付 |

### 商家侧违规
| 行为 | 处理 |
|------|------|
| 售假 | 店铺清退，保证金扣除 |
| 虚假发货 | 扣分 + 赔付 + 限制发货权限 |
| 拒绝履行三包 | 强制赔付 + 扣分 |
| 诱导用户取消订单 | 扣分 + 赔付差价 |
| 骚扰用户 | 警告，二次违规店铺降权 |

## 投诉渠道

### 平台内
1. 在线客服（App 内，7×24 小时）
2. 客服热线 400-XXX-XXXX（7×24 小时）
3. 订单详情页「投诉商家」

### 平台外
1. **12315** 全国消费者投诉举报热线
2. 全国 12315 平台网站/小程序
3. 当地消费者协会
4. 互联网法院在线诉讼（小额纠纷）

### 投诉时效
- 平台内投诉在订单完成后 **90 天内** 有效
- 12315 投诉在权益受损 **3 年内** 有效

## 常见问题

### 商家一直不回复怎么办
超过 **48 小时** 未响应，可直接申请平台介入，无需等待商家回复。

### 平台仲裁结果不满意怎么办
可向 12315 投诉，或通过互联网法院提起诉讼。平台的仲裁结论不排除用户依法维权的权利。

### 商家要求私下转账解决
**拒绝**。所有赔付必须通过平台流程，私下转账不受平台保护，且可能是诈骗。

### 投诉会被商家知道是我吗
会。纠纷处理需要双方知情，但平台不会向商家提供用户的完整手机号、地址等信息（仅提供订单相关信息）。

### 举证材料提交后能修改吗
在仲裁结论出具前可补充材料，但不能删除已提交的证据。补充材料需在 48 小时举证期内完成。
